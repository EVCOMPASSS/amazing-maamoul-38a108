# EV Compass

EV Compass is a modern, futuristic landing page concept for an EV route-planning and charging
aggregator for India. It presents the product vision: trip planning between two locations, EV
model and real-world range selection, route calculation with charging stops, live charger
discovery across multiple networks, and a preview of upcoming mobile app and roadmap features.

The site uses a dark, neon-blue, glassmorphism aesthetic inspired by premium EV brands, with
smooth animations and a fully responsive layout. 

## Tech Stack

- [TanStack Start](https://tanstack.com/start) (React 19 + TanStack Router)
- Vite 7
- Tailwind CSS 4
- lucide-react icons
- Deployed on Netlify

## Running Locally

Install dependencies and start the dev server:

```bash
pnpm install
pnpm dev
```

The app runs at `http://localhost:3000` by default.
